# Импорт старой переписки

Ключевые слова: импорт архив история telegram desktop json файл result старые сообщения cancelimport

## Подготовка файла

В Telegram Desktop откройте нужный чат, выберите экспорт истории и формат JSON без медиа. Отправьте боту в личном чате файл `result.json`. Максимальный размер — 5 МБ, максимум — 10000 сообщений. Большой чат нужно экспортировать отдельными диапазонами дат.

## Обработка архива

Импорт выполняется в фоне пакетами по 40 сообщений. Прогресс хранится в профиле, а сырой архив после обработки не записывается как отдельный файл. `/cancelimport` прекращает дальнейший разбор; уже извлечённые записи сохраняются.

Архивные сообщения могут пополнить решения, планы, встречи и историю в рамках включённых навыков. Они никогда не создают и не изменяют события календаря и не запускают напоминания.

## Ограничения истории

Обычный Telegram Bot API не позволяет автоматически получить старую переписку. Архив пока не объединяется автоматически с живой группой: извлечённые из него планы доступны в личном профиле. В режиме AI-поддержки файлы не импортируются; сначала используйте `/back`.
