# Встречи и календари

Ключевые слова: встреча событие календарь согласие дата время перенос отмена google яндекс caldav

## Условия создания встречи

Событие создаётся только когда одновременно выполнены условия:

- группа подключена к профилю зарегистрированного администратора;
- владелец этого профиля сам участвует в договорённости;
- участники явно согласовали встречу;
- дата, время начала и окончания однозначны;
- встреча находится в будущем;
- включено отслеживание встреч;
- разрешена запись в календарь;
- подключён и выбран доступный для записи календарь;
- отдельная проверка сопоставила действие с цитатами обсуждения.

Предложение, вопрос, шутка, цитата чужих слов или неясное «завтра утром» без достаточного контекста не должны создавать подтверждённое событие.

## Перенос и отмена

Бот переносит и отменяет только события, которые сам создал и связал с записью обсуждения. Для изменения нужна новая явная договорённость. Внешние изменения в календаре непрерывно не отслеживаются. Массовые приглашения участникам не отправляются.

## Google Calendar

Для подключения нужен Mini App по постоянному HTTPS-адресу и настроенное OAuth-приложение Google. Для создания событий требуется разрешение записи. После изменения запрашиваемых прав Google подключение нужно пройти повторно. В тестовом режиме OAuth пользователь должен быть добавлен в список test users приложения Google.

## Яндекс Календарь

Вход через Яндекс ID не всегда даёт доступ CalDAV. В таком случае в Mini App используется отдельный пароль приложения категории «Календарь». Основной пароль аккаунта вводить нельзя. Успешный вход в Яндекс ID сам по себе не подтверждает доступ к календарю.

## Если событие не появилось

Проверьте `/settings`: включены ли отслеживание встреч и запись, выбран ли календарь, действительно ли владелец профиля участвовал в явном согласовании и указано ли точное время. При неизвестном сетевом результате сначала проверьте календарь вручную; не просите создать то же событие повторно, пока не исключён дубль.
