PERSONAL AGENT

Настройки

Ваш помощник, ваши правила.

Откройте приложение из Telegram для доступа к настройкам.

Навыки агента

Для группы администратор включает обработку командой /track. Встречи меняют ваш календарь только с вашим согласием в обсуждении и при разрешённой записи.

Поведение

Получатели должны сначала запустить бота. Чужие сообщения не становятся командами вашему агенту.

Уведомления

Календари

После изменения прав подключите Google повторно. События не создаются одновременно в обоих календарях без вашего поручения.

Память

Не более 80 последних сообщений на обсуждение. Решения и история хранятся отдельно. При достижении лимита запись приостанавливается; важные данные не удаляются молча.

Открыть официальный вход

Вход происходит на стороне провайдера. Google может открыть системный браузер; после входа вернитесь к боту.

Яндекс через пароль приложения

Если OAuth не даёт доступ к календарю, используйте отдельный пароль приложения «Календарь» из Яндекс ID. Основной пароль не вводите.

Доступ к вашему профилю есть только у вас. Подключения можно удалить в любой момент.
